# Project Gantt Editor — 0.1.2-preview

基于用户原始单文件源码的保守修复预览版。双击index.html使用。尚未浏览器验收。

## 变化与限制
- 原界面保留；自动演示和自动排程关闭。汇总日期/进度也不会自动更新。
- JSON导入增加校验、备份及确认。浏览器可能要求允许下载，请核对JSON备份已下载。
- 旧版数据不删除；新版独立存储。没有多项目隔离、多人协作和完整撤销机制。
- XML仅按天展示任务、层级、进度和资源姓名；完整原时间和前置关系记录于来源元数据。依赖不画线，不支持XML写回。
- 日历、成本、基线等不完整导入，必须另行保留原XML，不能将本应用当作原XML备份。
- 旧Excel导入暂禁用，导出保留。
- 仅接受正整数任务ID；导入上限5000任务、跨度约30年，不代表已测试承载能力。
- 只修复已定位的部分安全路径，未完成完整安全审计。

## GitHub上传
建议先创建私人仓库。解压项目包，把内部文件上传到仓库，而不是只上传ZIP。不要提交公司项目XML/JSON/MPP或敏感截图。网页上传不一定遵守.gitignore，必须人工确认。作者和第三方来源核对前不附加开源许可证。
